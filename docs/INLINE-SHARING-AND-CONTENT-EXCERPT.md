# Inline sharing and content excerpt

This additive patch is based on e0ea5e4 (0.2.0-beta.9). It adds no builder dependency and does not change event storage, occurrence selection, or the Divi module.

Use `[wp_seed_event_share layout="inline"]` in a WordPress core Shortcode block to place directly visible copy and email actions in a template. The shortcode resolves the current event through the existing public context; an optional `id` follows the existing shortcode convention. The copy URL and mailto are generated by `wp_seed_events_event_share_data()`.

`wp_seed_events_render_event_share_menu($event, 'inline')` renders the same presentation. Calls with one argument, including the existing Divi module, retain the menu markup and labels. An unknown layout also falls back to the menu. A template that explicitly renders the shortcode for its current event does not receive a second automatic share menu. This suppression is scoped to that template render and restored in a `finally` block. Other events and subsequent renders cannot suppress it.

Inline feedback uses a visible `role="status"`, polite live region. Native button/link keyboard behavior is retained. Decorative glyphs are hidden from assistive technology; changing the copy label preserves its icon. The existing clipboard fallback restores focus. Site colors, spacing, responsive layout, and focus styles belong in the site composition, scoped to its wrapper.

The optional `description_excerpt` dynamic field returns the first 28 words of authored description as plain text, using the existing description extraction helpers. It never alters the manual short description or the existing `excerpt` field. It is exposed to Gutenberg bindings and their authorized edit-context preview. This lets a card show structured dates and an editorial excerpt when a manual summary already contains dates. No dates or event IDs are hardcoded in this field.

Validation: `inline-share-harness.php`, `template-inline-share-harness.php`, `description-excerpt-harness.php`, `inline-share-script.test.js`, and `gutenberg-block-bindings-preview-harness.php`. The last harness also updates its previously stale preview allowlist to include the existing programming and calendar fields. Relevant existing Gutenberg, rich content, dates, Divi sharing, computed style, and preview tests were run. See the site V2 report for pre-existing failing harnesses and live validation limits.

Deployment scope: TherapsyCorporel only. No publication or deployment to PDE; no merge into the canonical branch.
